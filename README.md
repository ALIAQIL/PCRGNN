# PCRGNN

## CV-ready project description

Developed a reproducible point-cloud learning project using PyTorch graph neural networks and multi-scale attention. Implemented graph-based point-cloud completion and an object-level 3D detection pipeline for the nuScenes mini dataset, including LiDAR preprocessing, scene-disjoint validation, box regression, 3D IoU, precision, recall, and per-class evaluation. Added dataset provenance tracking, SHA-256 integrity checks, and transparent reporting that separates real source data from derived and synthetic samples.

## Project scope

This repository contains two explicitly separated, notebook-first tracks:

1. [pc_rgnn_pcl_integrity_demo.ipynb](pc_rgnn_pcl_integrity_demo.ipynb) verifies eight real public PCL test-corpus files and demonstrates graph completion and multi-scale attention. Its derived views and synthetic midpoint points retain source identifiers. Because the manually assigned filename labels do not provide a class-balanced source-aware holdout, it reports no classification accuracy.
2. [nuscenes_mini_pcrgnn_detection.ipynb](nuscenes_mini_pcrgnn_detection.ipynb) is a real annotated-data development track for the official nuScenes mini split. It loads local LiDAR and boxes through the official devkit, creates scene-disjoint object crops, and reports center, size, yaw, axis-aligned 3D IoU, precision, recall, and per-class diagnostics.

The static frontend was removed so the notebooks and audit artifacts are the primary project surface.

## Integrity status

The eight local PCD files are pinned to PCL revision 66e1d0ea8cc3fa54820eb38e18ad0adac6345b94. The manifest records each upstream URL, byte count, and SHA-256 digest:

- [data/pc_rgnn/provenance.json](data/pc_rgnn/provenance.json)
- [docs/DATA_CARD.md](docs/DATA_CARD.md)
- [verify_integrity.py](verify_integrity.py)

Run the local and remote verification:

~~~bash
python verify_integrity.py --online
~~~

The PCL filenames are used as manual project labels, not official benchmark annotations. Raw files, derived normalized/subsampled views, and synthetic completion points are described separately. The former augmented-copy validation score is not presented as trustworthy generalization evidence.

## nuScenes mini detection track

Download v1.0-mini through the official nuScenes distribution and keep the raw dataset outside Git. Then install dependencies and point the notebook at it:

~~~bash
pip install -r requirements.txt
export NUSCENES_ROOT=/path/to/nuscenes
~~~

The notebook uses official scene, category, pose, LiDAR, and box tables. It enforces a scene-disjoint train/validation split and performs an object-level development experiment from ground-truth-centered crops. Results are mini-split development diagnostics, not full-dataset leaderboard claims. The reported IoU is axis-aligned diagnostic IoU rather than official oriented nuScenes AP.

If nuScenes is not mounted, the notebook skips data-dependent cells with setup instructions instead of fabricating results.

## Scope and limitations

This project is intentionally honest about evidence boundaries. PCL supplies eight real source files, not 160 independent scans. Augmentation cannot increase the number of independent sources. The nuScenes notebook is a compact object-level detector and does not replace a full-scene proposal pipeline or official benchmark evaluation.
